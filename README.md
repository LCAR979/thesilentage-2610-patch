# The Silent Age 中文补丁

Steam Windows 版的非官方中文补丁，附可选加速和第10章卡关修复。当前版本 **v1.1.0**。

## 开始使用

1. [下载补丁 ZIP](https://github.com/LCAR979/thesilentage-2610-patch/releases/download/v1.1.0/TheSilentAge_Chinese_2610_v1.1.0.zip)。
2. 退出游戏。右键下载的文件，选择“全部解压”。
3. 打开解压后的文件夹，双击 **Tools.cmd**，点击 **“安装 / 更新汉化”**。

完成后进入游戏，选择**中国国旗**即可使用中文。

**没找到游戏？** 在 Steam 游戏库中右键 The Silent Age → 管理 → 浏览本地文件。回到工具箱，点“浏览…”，选择刚才打开的文件夹。

## 想玩快一点？

退出游戏，在工具箱点**“安装加速”**：走路约快 2 倍，剧情和对白约快 3 倍。

游戏中按 **F6** 切换正常速度 / 加速。每次启动默认加速；加速时人声会变尖，背景音乐照常播放。不想用了就点“卸载加速”。

## 第10章卡在医生房间？

到了未来的医生房间，怎么点都没反应时，退出游戏，点**“修复结局”**。工具会自动备份存档。

重新进入游戏，点“继续”。如果装了加速，先按 F6 切回正常速度，然后点击医生。

只有遇到这个问题才需要修复。想撤销时，退出游戏再点“撤销结局修复”；已经继续游玩的存档可能无法撤销，以免影响进度。

## 恢复原版英文

先在游戏中切回英文，再退出游戏。在工具箱点 **“恢复原版英文”** 即可。

重新安装汉化后，加速会关闭。想继续加速，再点一次“安装加速”。
