The Silent Age  中文2610补丁 @lcar979 (Steam)

发布日期：2026年10月4日
翻译、补丁： GPT-6.1 Sol Light
版本： 1.0.0

这是适用于 Steam Windows 版的非官方简体中文补丁。
适用版本：Steam build 3358273，Unity 2018.2.9f1。
可以直接安装到匹配版本的官方原版游戏，不需要先下载或安装其他汉化补丁。

这个补丁做了什么
1. 中文文案重译与润色
   结合英文原文和旧中文，重写主线对白、场景独白及大量物品互动反馈。
   使用更自然的中文口语，根据人物和情绪保留粗口、自嘲与笑话。
   修正部分误译、漏句及解谜细节，统一人物称谓和物品名称。
   保留原本合适的短句与名称，并核对文本中的脚本控制标记和分段。
2. 中文显示修复
   为中文配置独立字体、材质和字体图集，解决旧补丁与当前游戏版本不匹配造成的显示问题。
   增加中文自动换行，修复长句超出文本区域的问题。
   调整中文标题页“点击开始”的居中位置。
   补齐门牌、姓名标签等被文本处理程序误跳过的条目。
3. 中英文切换
   启用游戏资源中原有但隐藏的中国国旗按钮，并调整按钮位置。
   修复从语言选择页面返回时加载错误场景的问题。
   可随时通过章节菜单的国旗按钮切换简体中文与英文。
   保留原版英文文本、字体、标题资源及英文换行逻辑。
4. 独立差分安装
   发布包只包含差分数据和安装程序，无须旧汉化作为前置。
   安装前核对源文件，生成后核对结果的 SHA256；不匹配时停止。
   自动保留 -backup 原版备份；支持更新、重复安装及通过恢复脚本还原原版。

安装方法
1. 完全退出游戏，解压 ZIP；不要在压缩包内直接运行。
2. 双击“应用补丁.cmd”，输入游戏安装文件夹的完整路径。
   示例：E:\SteamLibrary\steamapps\common\The Silent Age
   输入的是包含 thesilentage.exe 的文件夹，不是 thesilentage_Data。
   也可以把游戏文件夹拖进提示窗口，然后按回车。
3. 脚本校验原版与补丁，先备份四个原版文件，再应用差分补丁。
4. 从 Steam 启动，通过章节菜单左上角国旗切换语言。
   中国国旗为简体中文（语言选择页第二行第四个），英国国旗为英文。
无需先装旧汉化。请保留整个解压目录，以便使用恢复脚本。
无需把脚本单独拖入游戏目录；两个 CMD 和配套 PS1、清单、差分文件需要放在一起。
如果把整个补丁目录的内容放进游戏根目录，脚本也能自动识别游戏路径。

备份文件与恢复方法
备份放在原文件旁边，命名如下：
thesilentage_Data\resources-backup.assets
thesilentage_Data\globalgamemanagers-backup
thesilentage_Data\level3-backup
thesilentage_Data\Managed\Assembly-CSharp-backup.dll
已有备份不会被覆盖；校验不通过时停止操作。
已安装此前双语言补丁的用户，脚本可从旧 .zh-original 或 .backup 原版备份生成以上备份。
卸载前建议在游戏内切回英文，然后完全退出游戏。
双击“恢复备份.cmd”，输入同一个游戏路径，即可恢复四个官方原版文件。
恢复前会核对全部备份及当前文件，恢复后保留备份，方便重新安装。
备份缺失或被修改、当前游戏文件被其他补丁修改时，会停止并显示错误。
也可在 Steam 验证游戏文件完整性，恢复官方文件。


当前限制
尚未完成十章逐场景通关验证，因此以“测试版”发布，不能保证所有场景排版都已实测。
