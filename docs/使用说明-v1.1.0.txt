The Silent Age 中文 2610 补丁 v1.1.0
维护：LCAR979（Steam：@lcar979）

最快使用方法
1. 从 GitHub Releases 下载 TheSilentAge_Chinese_2610_v1.1.0.zip。
2. 完全解压到任意文件夹，退出游戏。不要在 ZIP 内直接运行。
3. 双击 Tools.cmd，打开中文工具箱，无需输入命令，也无需管理员权限。
4. 工具会自动寻找 Steam 游戏目录；找不到时点“浏览”，选择包含 thesilentage.exe 的文件夹。
   Steam → 右键游戏 → 管理 → 浏览本地文件，可以查看这个目录。
5. 点击“安装 / 更新汉化”，等待完成。启动游戏，选择中国国旗切换中文。
6. 想加速时，退出游戏，在工具箱点击“安装加速”。

本次译文修改
第一章接待处烟灰缸：
旧：“这是谁把一整罐骨灰倒里面了？我明明早上才清空的。”
新：“这是谁把一整罐烟灰倒里面了？我明明早上才清空的。”
英文用了“有人倒了一只 urn”来夸张烟灰量；本次按维护者要求明确写作烟灰。
修订记录见 extras/translation-fix.json。没有修改其他对白。

加速功能（可选）
人物行走约 2 倍；剧情动画、对白等待和语音约 3 倍。
每次启动默认开启，游戏中按 F6 切换正常速度 / 加速。
语音通过提高播放速率加速，音调会变高；背景音乐不加速。
这是全局时间倍率，不是跳过剧情。请在时序敏感场景按 F6 使用正常速度，尤其第10章医生房间。
无需额外启动器、常驻软件或联网。不会直接修改成就或存档。
工具箱的“卸载加速”恢复安装前的汉化脚本，保留汉化和存档。
加速备份：thesilentage_Data/Managed/Assembly-CSharp.dll.speedmod-backup。
此 Mod 只支持本项目 v1.0.0/v1.1.0 脚本，其他脚本校验不符时会拒绝安装。
重新安装完整汉化会还原正常速度；需要加速时再点击“安装加速”。

第10章结局卡住（按需使用）
适用现象：主角到未来医生房间后，点击没有反应，无法继续。
1. 完全退出游戏，用玩游戏的同一 Windows 账户双击 Tools.cmd。
2. 点击“修复结局”。工具先导出完整注册表存档，并记录三个字段的原始值。
3. 仅当当前章节=10、场景=115_sanatorium_office、点击阻挡值=1 时继续。
4. 工具移除该阻挡及医生对话触发器的持久化状态，并清除残留对白对象。
5. 重新启动游戏，继续游戏，手动点击医生。建议先按 F6 回到正常速度。
备份目录：%LOCALAPPDATA%\TheSilentAge2610\Backups。
退出游戏后可点“撤销最近一次结局修复”，仅恢复三个字段，不覆盖其他进度。
如果已经继续游戏、离开该场景或这些字段发生变化，自动撤销会拒绝执行，避免破坏后续进度。
完整 .reg 备份用于手动灾难恢复；双击导入会覆盖游戏偏好和相应进度，请仅在确需回退时使用。
本工具不清空存档、不重置章节、不解锁成就，也不是修复所有结局问题的通用补丁。
已知存档软锁经过实际修复后可以通关；因为三个字段同时修改，不能认定具体根因已经证明。
未发现证据表明问题由汉化造成。此版本是针对该状态的恢复工具，不声称彻底消除了源码中的触发时序问题。

卸载全部汉化
先在游戏中切回英文，退出游戏，运行“恢复备份.cmd”，选择同一游戏目录。
其恢复的是安装汉化前的四个官方文件，备份不会被删除。
也可通过 Steam 验证游戏完整性恢复官方文件；该操作通常不恢复已修改的注册表存档。

仅想更新旧汉化
仓库源码 ZIP 也包含 Tools.cmd、extras 和小型加速差分。
已安装 v1.0.0 的用户可以直接双击 Tools.cmd 修正译文及使用其他工具。
尚未安装汉化的用户必须下载 Releases 完整发布包，源码 ZIP 不包含完整汉化数据。
旧版译文更新备份：thesilentage_Data/resources.assets.2610-v1.0.0-backup。
